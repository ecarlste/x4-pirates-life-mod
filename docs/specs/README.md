# Feature specs

Once we agree on a feature's design, it gets a spec here, copied from [`_template.md`](_template.md). A spec should give an agent enough to build the feature without guessing, and give a human enough to question the decisions. Keep it short.

If the build changes the plan, update the spec in the same PR.
