# Rejected design ideas

Design ideas Erik has rejected, kept so we know what was decided and why, and so they aren't proposed again unchanged. See [PROJECT.md, Workflow](../PROJECT.md#workflow).

- **Moving an idea here:** put it in its own file (or a section of a related file) with what was proposed, why it was rejected, the date, and a link to where it came from. Leave a one-line pointer in the original note.
- **Reopening:** if someone thinks they've solved the reason an idea was rejected, ask Erik. Once he approves, the idea moves back into [`research/`](../research/README.md) and its row is removed here.
